# SkyOSINT

SkyOSINT is a beginner-friendly, all-in-one **OSINT (Open Source Intelligence) CLI tool** written in Python.

It is designed to help **beginner ethical hackers and OSINT learners** understand how OSINT tools work using only:
- Public information  
- Passive techniques  
- No APIs  
- No hacking  
- No tracking  

---

## 👤 Creator

**Abyss Hub**

---

## ✨ Features

- 📧 Email OSINT (format check, domain, MX record)
- 📱 Phone OSINT (country/region inference)
- 🌐 Domain OSINT (WHOIS, DNS, resolved IP)
- 🖥️ IP OSINT (reverse DNS, private/public)
- 📍 Location Intelligence (passive only)
- 👤 Username OSINT (public profile checker)
- 📝 Automatic report saving (TXT + session JSON)
- 📂 Built-in reports folder
- 🎨 Colorful CLI menu

---

## 🛠 Requirements

- Python 3.8 or newer  
- Internet connection (for web-based OSINT)

---

## 📦 Installation

### 1. Clone the repository
```bash
git clone https://github.com/SKYBERZ/SkyOSINT.git
cd SkyOSINT
```
### 2. Then install all requirements use this command
```bash
pip install -r requirements.txt
```
### 3. open SkyOSINT Menu
#### Windows
```bash
python skyosint.py
```
#### Linux
```bash
python3 skyosint.py
```
